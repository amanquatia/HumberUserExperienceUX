Overview of Time Processing System (TPS)

The Employee Time Processing System (TPS) is an enterprise web application used to record, review, and approve employee working hours across the organization. TPS supports daily and weekly time entry, project-based hour tracking, and automated validation to ensure accurate reporting of time worked. The system maintains compliance with labor policies, overtime rules, and organizational pay structures.

TPS is used by three primary groups of users, each with distinct responsibilities.

  • Employee: Employees enter their hours, breaks, tasks, and project assignments for each day in the pay period.

  • Manager: Managers review submitted timesheets, confirm accuracy, request corrections when needed, and approve entries for payroll processing.

  • Payroll: Payroll staff finalize approved timesheets, reconcile recorded hours with pay rules, and generate audit-ready records that support tax calculations, compliance reporting, and organizational payroll cycles.

This documentation page provides step-by-step instructions, role-based guidance, and visual examples to help users complete common TPS tasks. Each section includes clear actions, accessible language, and descriptive imagery to support all users, including those relying on assistive technologies. The guide is designed to help employees, managers, and payroll personnel perform their responsibilities confidently and correctly.

Update Employee Profile

Employee profile information can be updated by managers, employees, and payroll staff as needed to maintain accurate records.

  1. Select "Employees" from TPS main dashboard
  2. Search for the employee.
  3. Select "My Profile".
  4. Update fields (Job Mobile Number, Contact Email, Address, Payment Mode, etc.).
  5. Changes are saved automatically when entered.

Enter Timesheet

Employees enter hours worked for each day in the pay period.

  1. Open "My Timesheets" from TPS main dashboard
  2. Select "Create New Timesheet".
  3. Select the appropriate date range from the "Pay Periods" dropdown menu.
  4. Enter Project, Task and hours for each day.
  5. Select "Add Line item" to add additional lines.
  6. Select "Save" to complete timesheet entry.

Approve Timesheet

Managers are expected to review and approve employee timesheets.

  1. Select "All Timesheets" from TPS main dashboard
  2. Open the "Pending Approvals" queue.
  3. Review hours, overtime, and project codes.
  4. Check for compliance issues.
  5. Add optional manager comments.
  6. Select "Approve" or "Reject".

Timesheet for Vincent Vega showing approved and rejected hours. Rejected entries require correction before managers can complete the approval.

Submit Timesheet

Employees are required to submit approved timesheets for payroll processing.

  1. Select "My Timesheets" from TPS main dashboard
  2. Select "Saved Timesheet".
  3. Verify all entries.
  4. Ensure no validation errors appear.
  5. Select "Submit Timesheet".
  6. Wait for submission confirmation message.

The payroll submission screen allows employees to review daily hours, confirm estimated taxes and projected net pay, and make any required corrections before final submission to payroll.

Frequently Asked Questions (FAQ)

  • Why can't I submit?
    Ensure all mandatory fields are completed and the timesheet is within the submission window.
  • Why was my timesheet rejected?
    Managers may reject entries for incorrect hours or missing project codes.
  • How do I correct errors?
    Open the rejected timesheet, fix highlighted issues, and resubmit.
